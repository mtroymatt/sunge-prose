# 孙割小作文（sunge-prose）

> 蒸馏孙宇晨（Justin Sun）《我的女友景甜》文风的可复用改写 Skill。

## 这是什么

一个把任意文本 / 故事 / 观点，改写成「情感零度 · 冰山 · 缺席叙事」冷调小作文的 AI Skill。

## 文风特征

- **数字账目承载情感** —— 精确到分的账本式叙述，钱（或数据）精确、情感隐形
- **真实素材缝合** —— 人名 / 地名 / 品牌 / 日期 + 一个当下技术细节，让虚构像泄密
- **象征物承担关系** —— 一个小物件贯穿全文，结尾变形回响
- **复沓主题句 + 反高潮留白** —— 真相点而不破，最高情绪压成一句废话
- **情感零度** —— 情绪只通过动作 / 物件 / 数字转译，绝不直写

## 目录结构

```
sunge-prose/
├── SKILL.md                 # 核心：文风本质 + 七步改写引擎 + 转换规则 + 校验标准
└── references/
    └── style-guide.md       # 完整范文 + 原作拆解要点 + 论点→意象对照速查
```

## 安装

将 `sunge-prose/` 目录复制到你的 skills 目录即可（如 WorkBuddy 的 `~/.workbuddy/skills/`，或 Claude Code 的 skills 路径）。

## 使用

对话中说「按孙割的文风改写」或「照这个叙述方式重写」，然后丢一段故事 / 观点即可。

## 免责声明

本 Skill 仅用于研究文体风格与写作技巧，不涉及对任何真实人物的评价或隐私；文风仿写属学习性质。
